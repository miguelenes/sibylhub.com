## Why

SibylHub currently has an empty application workspace, so each requested surface would otherwise be created with unrelated tooling, commands, and runtime assumptions. A single Turborepo foundation will establish a reproducible developer workflow across JavaScript, PHP, and Rust while giving the public web, internal backoffice, backend services, CLI, and documentation clear ownership boundaries from the start.

## What Changes

- Add a pnpm-managed Turborepo workspace with explicit app locations and root commands for development, builds, linting, type checking, testing, and cleaning.
- Add `web`, an Astro site with React 19 islands, HeroUI v3 styling/components, TypeScript, and Cloudflare Wrangler deployment configuration.
- Add `backoffice`, a Laravel application created through the Laravel installer and configured as a Filament 5 panel application.
- Add `backend`, a Rust Cargo application that exposes an HTTP API and webserver entry point with explicit configuration, error handling, logging, and test seams.
- Add `cli`, a separate Rust Cargo command-line application for invoking supported backend/domain workflows.
- Add `docs`, a Docusaurus TypeScript documentation site with local development and static production build commands.
- Configure Turborepo task dependencies and cache outputs for the mixed-runtime workspace, while keeping long-running development servers and side-effecting operations uncached.
- Add root and relevant nested `AGENTS.md` guidance describing package ownership, commands, testing gates, secrets handling, and cross-runtime boundaries.
- Add baseline environment templates, ignore rules, CI-ready validation commands, and documented deployment boundaries without introducing production credentials or live deployment configuration.

## Capabilities

### New Capabilities

- `monorepo-foundation`: A reproducible multi-runtime workspace layout, package-manager contract, Turborepo task graph, shared developer commands, caching policy, environment conventions, and agent guidance.
- `web-application`: An Astro + React 19 public web application with HeroUI v3 UI foundations and Cloudflare Wrangler build/deployment configuration.
- `backoffice-application`: A Laravel application with a Filament 5 backoffice panel and isolated PHP dependencies and commands.
- `rust-services`: A Cargo-managed backend HTTP API/webserver and a separate Cargo CLI with shared, testable domain/configuration boundaries.
- `documentation-site`: A Docusaurus TypeScript documentation application with local development, validation, and static build workflows.

### Modified Capabilities

None. The repository has no existing specs or implemented capabilities.

## Impact

This change introduces the repository layout, root and app-level manifests/configuration, lockfiles generated by the selected package managers, TypeScript/React/Astro/Docusaurus dependencies, Laravel and Filament dependencies, Rust Cargo manifests, baseline tests, CI validation configuration, and agent documentation. It defines local integration seams between the web/docs clients, backoffice, backend, and CLI but does not implement product domain features, authentication, persistence schemas, provider integrations, live Cloudflare resources, production infrastructure, or secret distribution.
